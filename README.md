# cryptage

[![CI](https://github.com/N4ole/cryptage/actions/workflows/ci.yml/badge.svg)](https://github.com/N4ole/cryptage/actions/workflows/ci.yml)
[![Licence : MIT](https://img.shields.io/badge/licence-MIT-blue.svg)](LICENSE)

Application de bureau pour chiffrer et déchiffrer des fichiers avec un mot de passe,
entièrement hors ligne : pas de serveur, pas de compte, pas de connexion internet.

> ⚠️ **Sans le mot de passe, les données chiffrées sont définitivement irrécupérables.**
> Il n'existe aucune porte dérobée ni procédure de récupération.

🚧 Projet en cours de développement. La documentation complète (utilisation, format
de fichier, choix cryptographiques, limites) sera ajoutée au fil des étapes.
